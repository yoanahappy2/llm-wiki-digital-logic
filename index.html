02 / 基礎概念LESSON / 03—12

邏輯閘：把 0 和 1 變成規則

邏輯閘（Logic Gate）接收 0 或 1，依規則輸出 0 或 1。

ABANDORXOR
00000
01011
10011
11110

NOT 只有一個輸入：NOT 0 = 1；NOT 1 = 0。

互動試試看

AND 0
OR 0
XOR 0
KEY IDEA

AND：只有 A=1 且 B=1，輸出才為 1。 OR：只要 A 或 B 其中至少一個是 1，輸出就是 1。 XOR：兩個輸入不同才輸出 1；1 XOR 1 = 0。

03 / 重要差異LESSON / 04—12

容易搞混：OR 和 XOR

當 A = 1、B = 1，OR 與 XOR 的結果剛好不同。

OR
1 OR 1
1

至少一個是 1，因此輸出 1。

XOR
1 XOR 1
0

兩個輸入相同，因此輸出 0。

KEY IDEA

別把 OR 和 XOR 混淆：當 A=B=1 時，OR=1、XOR=0。

04 / 從小元件組大系統LESSON / 05—12

NAND：可以組出其他邏輯閘

NAND 是 AND 之後反相；把 NAND 重複組合，能實作其他基本閘。

ANDA ∧ B→NOT¬(A ∧ B)= NAND
範例NAND(A, A) = NOT(A)
KEY IDEA

NAND(A,B)=NOT(A AND B)，且 NAND(A,A)=NOT(A)。

05 / 應用到運算LESSON / 06—12

半加器：二進位怎麼相加？

用兩個邏輯運算，就能做最簡單的二進位加法。

HALF ADDER
Sum = A XOR B
Carry = A AND B

若 A = 1、B = 1，答案是二進位 10：和位 0、進位 1。

試著切換兩個輸入

Sum 0
Carry 0

0 + 0 = 00（2 進位）

KEY IDEA

把 1+1=10 標為二進位；半加器沒有額外輸入進位。

06 / 記憶與時鐘LESSON / 07—12

D Flip-Flop：把資訊記住

組合邏輯不儲存以前的結果；D Flip-Flop（DFF）能記住一個位元。

D正緣 DFFQ
CLK
① 上升緣之前

D 可以改變，Q 暫時維持舊值。

② 時鐘上升緣

以正緣觸發 DFF 為例，把 D 的值載入 Q。

③ 下一個上升緣前

Q 維持剛才記住的值。

KEY IDEA

正緣觸發只是本簡報選用的 DFF 類型，不代表全部 DFF 都是正緣觸發。

07 / 核心區別LESSON / 08—12

組合邏輯 vs. 時序邏輯

COMBINATIONAL

組合邏輯

輸出取決於現在的輸入

例：AND、OR、加法器

SEQUENTIAL

時序邏輯

輸出或下一狀態還依賴記住的狀態

例：暫存器、同步計數器、FSM

KEY IDEA

不要把「同步時序電路常用時鐘」擴大成「所有時序電路都一定有時鐘」。

08 / 控制流程LESSON / 09—12

FSM：讓電路依照步驟行動

有限狀態機（FSM）描述「目前在哪個狀態，以及什麼條件會切到下一個狀態」。

OFF燈熄滅
按一下按鈕 ⇄
ON燈點亮

目前狀態：OFF

這是我們自製的「開關燈」簡化示例：每次按下視為一次事件。實體電路還需要處理按鈕去彈跳。

KEY IDEA

狀態代表系統目前記住的必要資訊。 下一狀態依目前狀態及輸入決定；轉移規則須沒有歧義。
